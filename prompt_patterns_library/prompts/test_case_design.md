# Test Case Design Prompt Template

**Role**: Act as a senior QA analyst with experience in software testing and test design techniques.

**Task**: Convert the provided feature description and requirements into clear, structured, and traceable test cases. Include positive, negative, boundary, and edge-case scenarios. Do not invent requirements or expected behavior that are not supported by the input.

**Input Placeholder**:
- Feature description: [FEATURE_DESCRIPTION]
- Requirements: [REQUIREMENTS]
- Acceptance criteria: [ACCEPTANCE_CRITERIA]
- Test environment: [TEST_ENVIRONMENT]

**Expected Output Format**:

Provide a table with the following columns:
1. Test Case ID
2. Related Requirement
3. Test Scenario
4. Preconditions
5. Test Steps
6. Test Data
7. Expected Result
8. Priority

After the table, list any ambiguities, missing requirements, or assumptions that need clarification.
