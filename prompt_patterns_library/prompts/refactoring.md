# Refactoring Prompt Template

**Role**: Act as a senior software engineer specializing in clean code and maintainable software design.

**Task**: Refactor the provided [LANGUAGE] code to improve readability, maintainability, and efficiency without changing its existing behavior. Explain meaningful changes and identify assumptions.

**Input Placeholder**:
- Programming language: [LANGUAGE]
- Source code: [CODE_BLOCK]
- Constraints: [CONSTRAINTS]
- Existing behavior or tests: [EXPECTED_BEHAVIOR_OR_TESTS]

**Expected Output Format**:
1. Refactored code in a fenced code block.
2. Summary of the changes.
3. Explanation of why the changes improve the code.
4. Assumptions or risks.
5. Suggested tests to confirm that the original behavior is preserved.
