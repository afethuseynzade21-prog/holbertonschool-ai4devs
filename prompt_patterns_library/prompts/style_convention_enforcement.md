# Style and Convention Enforcement Prompt Template

**Role**: Act as a senior software developer and code quality reviewer with expertise in [LANGUAGE] coding standards and best practices.

**Task**: Review and revise the provided source code to ensure that it follows consistent naming conventions, formatting rules, and language-specific coding standards. Preserve the original functionality and avoid unnecessary changes.

**Input Placeholder**:
- Programming language: [LANGUAGE]
- Source code: [CODE_BLOCK]
- Style guide or coding rules: [STYLE_GUIDELINES]
- Project-specific conventions: [PROJECT_CONVENTIONS]

**Expected Output Format**:
1. Revised code in a fenced code block.
2. List of style and convention issues identified.
3. Explanation of the changes made.
4. Any rules that could not be applied and the reasons.
5. Recommendations for maintaining consistent code quality.
