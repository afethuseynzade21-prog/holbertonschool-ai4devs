# API Documentation Prompt Template

**Role**: Act as a senior technical writer specializing in API documentation and developer experience.

**Task**: Generate clear, accurate, and structured documentation for the API based on the supplied source code or specification. Do not invent endpoints, parameters, authentication requirements, or response fields that are not present in the input.

**Input Placeholder**:
- API source code or specification: [API_SOURCE_OR_SPEC]
- Base URL and API version: [BASE_URL_AND_VERSION]
- Authentication details: [AUTH_DETAILS]
- Request and response examples: [REQUEST_RESPONSE_EXAMPLES]
- Intended audience: [TARGET_AUDIENCE]

**Expected Output Format**:
1. API overview and purpose.
2. Endpoint documentation with HTTP method and path.
3. Description of parameters, data types, and required fields.
4. Authentication requirements, if provided.
5. Example requests and responses.
6. Possible error codes and explanations.
7. Limitations or missing information that needs confirmation.
