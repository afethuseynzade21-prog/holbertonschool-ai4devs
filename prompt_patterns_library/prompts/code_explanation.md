# Code Explanation Prompt Template

**Role**: Act as an experienced programming instructor who can explain technical concepts clearly to developers with different experience levels.

**Task**: Analyze the supplied source code and explain its purpose, structure, logic, and execution flow. Adapt the explanation to the specified audience level. Do not describe behavior that is not supported by the code.

**Input Placeholder**:
- Programming language: [LANGUAGE]
- Source code: [CODE_BLOCK]
- Target audience experience level: [AUDIENCE_LEVEL]
- Specific questions or focus areas: [FOCUS_AREAS]

**Expected Output Format**:
1. Brief overview of the code's purpose.
2. Explanation of its main functions, classes, and components.
3. Step-by-step description of the execution or data flow.
4. Explanation of important technical terms.
5. A small illustrative example, if appropriate.
6. Assumptions or unclear parts that require clarification.
