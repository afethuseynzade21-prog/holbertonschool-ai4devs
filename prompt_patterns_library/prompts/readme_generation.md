# README Generation Prompt Template

**Role**: Act as a senior technical writer specializing in software project documentation.

**Task**: Create a clear and practical README file that helps developers understand, install, configure, run, and use the supplied software project. Use only the information provided and mark missing details for confirmation instead of inventing them.

**Input Placeholder**:
- Project name and overview: [PROJECT_OVERVIEW]
- Project structure: [PROJECT_STRUCTURE]
- Dependencies and versions: [DEPENDENCIES]
- Installation and configuration instructions: [INSTALL_CONFIG]
- Run and test commands: [RUN_TEST_COMMANDS]
- Usage examples: [USAGE_EXAMPLES]
- License and contribution details: [LICENSE_AND_CONTRIBUTIONS]

**Expected Output Format**:
1. Project title and overview.
2. Main features.
3. Prerequisites.
4. Installation and configuration instructions.
5. Instructions for running and using the project.
6. Testing instructions.
7. Project structure, if relevant.
8. License and contribution information, if provided.
9. A list of missing details that require confirmation.
